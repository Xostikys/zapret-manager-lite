# Zapret Manager Lite — LuCI, редакция 3

Модификация Zapret Manager от StressOzz: убирает рекламные блоки и отдельную
панель вне LuCI, делает карточки прозрачными и отключает CSS-анимации.
Forkozz, игровые профили и настройки работающих движков сохраняются.
Это дополнение к исходному Manager, а не новый движок обхода.

## Установка

Сначала опубликуйте содержимое архива v3 в `Xostikys/zapret-manager-lite`, ветка
`main`, с сохранением папок. Пока файлы не заменены, команда получает старый выпуск.

В PowerShell:

```powershell
ssh root@192.168.1.1 'd=$(mktemp -d /tmp/zm-lite.XXXXXX) && { wget -O $d/install.sh https://raw.githubusercontent.com/Xostikys/zapret-manager-lite/main/install.sh && sh $d/install.sh; r=$?; rm -f $d/install.sh; rmdir $d; exit $r; }'
```

В SSH-консоли роутера:

```sh
d=$(mktemp -d /tmp/zm-lite.XXXXXX) && { wget -O "$d/install.sh" https://raw.githubusercontent.com/Xostikys/zapret-manager-lite/main/install.sh && sh "$d/install.sh"; r=$?; rm -f "$d/install.sh"; rmdir "$d"; exit "$r"; }
```

Повторная установка обновляет дополнение. Существующий Manager не переустанавливается
и не понижается до сохранённой версии. На чистой системе запускается изменённый
установщик Manager 5.081; движки/серверы настраиваются отдельно. Чистая установка
и редакция 3 на физическом роутере ещё не проверены.

Нужны OpenWrt, LuCI, root, работающий cron, ucode с fs, UCI, BusyBox-утилиты,
tar и sha256sum. Символьные ссылки в управляемых путях, включая режим UI в RAM,
не поддерживаются: подготовка откажет до изменения файлов Manager.

## Что изменено в редакции 3

- Одна операция для страниц, меню, backend/RPC и отдельного слушателя uhttpd.zmweb.
- Полная подготовка и проверка перед записью; проверка целостности после записи.
- UCI подготавливается в собственном каталоге изменений. Чужие незавершённые
  настройки не сохраняются; остальные секции uhttpd сравниваются перед применением.
- При обычной ошибке записи или reload выполняется восстановление. После
  принудительного завершения сохраняется журнал для команды `recover`.
- Восстановление сначала проверяет все файлы; оно не накладывает старую панель
  поверх изменённой версии Manager. Возвращаются и удалённые страницы, и слушатель.
- Временные файлы и резервная копия находятся в закрытых каталогах root.
- Одно задание cron раз в 5 минут. Нет постоянно работающего наблюдателя.
  При неизменных входных файлах выполняется сверка без копирования компонентов
  и без перезаписи файлов на flash. Состояние наблюдений хранится в /tmp.

После обновления исходного Manager очистка обычно занимает 5–10 минут:
нужны одинаковые наблюдения с интервалом минимум 4 минуты. До очистки исходное
обновление может вернуть отдельную панель и рекламу. Незнакомая структура,
занятая панель, нехватка места или изменения настроек откладывают/блокируют очистку.
Гарантии совместимости со всеми будущими версиями нет.

При изменении конфигурации веб-сервера/RPC выполняется reload соответствующей
службы; возможен повторный вход в LuCI. nfqws, sing-box, firewall, DNS и их
пользовательские конфиги дополнение не меняет. Сама установка исходного Manager
на чистой системе имеет отдельные, более широкие действия.

## Проверка и откат

После установки проверить подготовку без изменения файлов Manager:

```sh
sh /etc/zm-local-ui/apply.sh check
```

Отключить только наше расписание:

```sh
sh /etc/zm-local-ui/apply.sh disable
```

Отключить расписание и вернуть файлы перед последней операцией редакции 3:

```sh
sh /etc/zm-local-ui/restore.sh
```

После аварийного прерывания, если есть сообщение о незавершённой операции:

```sh
sh /etc/zm-local-ui/apply.sh recover
```

Откат восстанавливает состояние перед последней правкой, а не обязательно
нетронутый оригинал: ранее установленные патчи могут уже присутствовать.
Старые резервные копии редакций 1/2 сохраняются, но новый откат их автоматически
не смешивает. Копия редакции 3: `/etc/zm-local-ui/backup-v3`.
При конфликте с новой версией сохраните копию и журнал; принудительно
перезаписывать файлы по старым контрольным суммам не следует.

## Проверки, безопасность и ресурсы

Подробности: [AUDIT.ru.md](AUDIT.ru.md), результаты модели: [TEST-RESULTS.json](TEST-RESULTS.json).
На ПК проверены сценарии установки, повторного применения, отката и ошибок.
UCI, ucode, права Unix и reload в интеграционных тестах моделировались.
Это не пентест роутера и не гарантия отсутствия уязвимостей исходного Manager,
OpenWrt или сторонних движков. Перед массовым распространением нужен тест устройства.

На вашем замере во время игры и YouTube было доступно около 84.6 МиБ RAM,
sing-box занимал около 63.6 МиБ RSS. Перекрашивание CSS не уменьшает эту память:
анимации обрабатывает браузер. Дополнение сокращает собственные фоновые действия.
Лимиты sing-box, сетевые буферы, offloading и игровые правила автоматически не меняются.

## Исходники и сборка

- `src/`: дополнение, преобразователи, резервирование/откат.
- `vendor/`: изменённый сохранённый установщик 5.081; это не последняя версия.
- `bootstrap.sh.in`, `build.py`: автономный установщик без Python на роутере.
- `SOURCES.json`: исходный commit и контрольная сумма изменённого установщика.

На ПК: `python build.py`, затем `python tests/verify_package.py`.
Встроенная SHA256 обнаруживает повреждение архива, но не является подписью
независимого доверенного автора. Установка из main доверяет текущему содержимому
репозитория. Для фиксированного выпуска замените main в URL на проверенный commit.

Исходный Manager продолжает использовать собственный механизм обновления и
загрузки стороннего ПО. Некоторые загрузки могут идти через зеркала. Эта цепочка
доверия не устранена локальной очисткой и требует отдельного аудита.

## Очистка сразу после обновления

Для проверенного механизма кнопки обновления LuCI дополнение добавляет запуск
очистки сразу после успешного завершения установщика. Оно заново устанавливает
этот обработчик в обновлённые компоненты. Постоянного процесса нет. Cron раз
в 5 минут остаётся страховкой для обновлений другими способами или отложенной
очистки. Краткое возвращение исходного оформления во время установки возможно.
Неизвестный шаблон новой версии требует адаптации: об ошибке сообщает журнал
`logread -e zm-local-ui`, подробности обновления — `/tmp/zm_update_install.log`.
Автоматическая совместимость со всеми будущими версиями не гарантируется.
Обработчик отключается вместе с нашим дополнением. На ПК проверены 5.081/5.085;
реальное обновление с этим обработчиком на роутере ещё предстоит проверить.
