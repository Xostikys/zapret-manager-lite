# Zapret Manager Lite

Модификация [Zapret Manager от StressOzz](https://github.com/StressOzz/Zapret-Manager)
для **OpenWrt и LuCI**. Убирает рекламные блоки VPN/Telegram, донатную вкладку
и отдельную панель вне LuCI. Карточки используют фон темы роутера,
CSS-анимации отключены. Авторство оригинального проекта сохранено.

Zapret, игровые стратегии и Forkozz работают через установленный Manager.
Пользовательские настройки nfqws, sing-box, DNS и firewall дополнение не переписывает.

## Установка одной командой

В SSH-консоли OpenWrt под `root`:

```sh
d=$(mktemp -d /tmp/zm-lite.XXXXXX) && { wget -O "$d/install.sh" https://raw.githubusercontent.com/Xostikys/zapret-manager-lite/main/install.sh && sh "$d/install.sh"; r=$?; rm -f "$d/install.sh"; rmdir "$d"; exit "$r"; }
```

Из Windows PowerShell:

```powershell
ssh root@192.168.1.1 'd=$(mktemp -d /tmp/zm-lite.XXXXXX) && { wget -O $d/install.sh https://raw.githubusercontent.com/Xostikys/zapret-manager-lite/main/install.sh && sh $d/install.sh; r=$?; rm -f $d/install.sh; rmdir $d; exit $r; }'
```

Замените `192.168.1.1` на адрес своего роутера. После установки откройте
**LuCI → Службы → Zapret Manager** и обновите страницу через **Ctrl+F5**.
Команда получает выпуск, который опубликован в ветке `main`.

Если Manager уже установлен, установщик сохраняет его текущую версию и применяет
модификацию. На чистом устройстве используется сохранённый изменённый установщик
Manager **5.081**; установка движков и настройка серверов выполняются отдельно в LuCI.
Для существующей рабочей установки этот старый установщик не запускается.

## Возможности

| Функция | Поведение |
|---|---|
| Интерфейс | Без рекламных баннеров и отдельной страницы Web UI; оформление наследует тему LuCI |
| Игры и Forkozz | Существующие стратегии, fake-файлы и маршрутизация сохраняются |
| Обновление Manager | Через штатную кнопку, напрямую с GitHub по HTTPS; без сторонних зеркал для установщика панели |
| Очистка после обновления | Запускается сразу после успешного обновления через проверенный механизм LuCI |
| Запасная проверка | Одно задание cron раз в 5 минут, без постоянного фонового процесса |
| Резервирование | Последняя копия, контрольные суммы, отдельный первый снимок, восстановление после прерывания |

Быстрые обновления от StressOzz сохранены. Если прямой GitHub недоступен,
обновление отменяется; небезопасного переключения на зеркало или отключения
проверки сертификата нет. `curl` нужен для этого способа обновления панели.
При изменении структуры будущей версии очистка может потребовать адаптации.

## Совместимость

Требуются OpenWrt, LuCI, `root`, работающий cron, ucode с модулем fs,
UCI и стандартные утилиты BusyBox. Python на роутере не нужен.
Режим хранения UI в RAM через символьные ссылки не поддерживается:
переключите панель на обычное хранение во flash перед установкой.

| Проверка | Результат |
|---|---|
| Cudy WR3000S v1, ubootmod, OpenWrt 25.12.4, aarch64_cortex-a53 | Пользователь подтвердил успешную установку и работу редакции 3 |
| Manager 5.083 → 5.085 | Обновление и повторное применение редакции 3 подтверждены на устройстве |
| Исходники Manager 5.081 и 5.085 | Локальные проверки преобразований shell/JSON/JS пройдены |
| Редакция 4, Manager 5.085 | Установка и применение правки Forkozz подтверждены выводом с роутера; полная проверка функций и следующего обновления ещё не завершена |
| Чистая установка и другие роутеры | Не подтверждены |

Подтверждение установки не заменяет проверку всех функций и следующего обновления.
Результаты тестов: [TEST-RESULTS.json](TEST-RESULTS.json).

## Обновления

**Обновить само дополнение:** повторите команду установки из этого README.

**Обновить Manager:** используйте штатную кнопку в LuCI. Сразу после успешной
установки запускается очистка и заново добавляется обработчик следующего обновления.
Старое оформление может кратковременно появиться во время установки.
Для обновлений другими способами и отложенной очистки остаётся cron.
Он ждёт стабильных файлов; обычно это 5–10 минут, при занятости панели — дольше.

Отключение дополнения останавливает наш cron и запуск очистки после обновления.
Чтобы снова включить их, повторите установку.

## Диагностика

Проверить возможность применения, не меняя файлы Manager:

```sh
sh /etc/zm-local-ui/apply.sh check
```

Применить очистку сейчас:

```sh
sh /etc/zm-local-ui/apply.sh apply
```

Посмотреть журнал:

```sh
logread -e zm-local-ui
```

Собрать локальный отчёт для проверки версий пакетов, слушающих портов и ACL:

```sh
sh /etc/zm-local-ui/security-report.sh
```

Скрипт ничего не отправляет в интернет. В выводе могут быть локальные адреса и
версии ПО; просмотрите его перед публикацией. Он не определяет доступность портов
с WAN и сам не проверяет CVE. Конфиги подписок и пароли в отчёт не включаются.

Если после обновления вернулась реклама: запустите `check`, затем `apply`.
При неизвестном шаблоне сохраните текст ошибки. Не отключайте защитные проверки.

## Отключение и восстановление

Отключить только дополнение, сохранив текущее оформление:

```sh
sh /etc/zm-local-ui/apply.sh disable
```

Отключить дополнение и восстановить файлы перед последним применением:

```sh
sh /etc/zm-local-ui/restore.sh
```

Восстановиться после незавершённой операции:

```sh
sh /etc/zm-local-ui/apply.sh recover
```

Текущая копия: `/etc/zm-local-ui/backup-v3` — имя сохранено для совместимости.
Первый снимок, созданный начиная с редакции 4: `/etc/zm-local-ui/first-snapshot`.
Он хранится отдельно и автоматически поверх новой версии не накладывается.
Оба снимка могут уже содержать прежние местные правки. Откат не обещает вернуть
нетронутый оригинал, если его не было на устройстве при создании копии.

Перед восстановлением проверяются контрольные суммы и отсутствие новой версии
файлов. При конфликте восстановление остановится. Копии не удаляйте до разбора.
Во время reload веб-сервера или RPC может потребоваться повторный вход в LuCI.

## Безопасность

Установщик панели скачивается с официального raw GitHub по HTTPS с проверкой
сертификата. Проверяются размер, начало/конец файла и shell-синтаксис.
Контрольная сумма записывается для диагностики. Это **не независимая цифровая
подпись** и не подтверждение безопасности скачанного кода.

По выбору владельца проекта сохранены быстрые обновления, без ручного одобрения
каждой версии. Доверие к аккаунту StressOzz и GitHub остаётся. Другие загрузчики
движков исходного Manager могут использовать свои зеркала и правила проверки.
Изменение этих механизмов требует отдельной работы и тестов.

Подробности: [SECURITY.md](SECURITY.md), [AUDIT.ru.md](AUDIT.ru.md).
При потере питания используется журнал восстановления; гарантии от физического
повреждения flash нет. Установка через `main` доверяет содержимому репозитория;
для фиксированной версии замените `main` в URL на проверенный commit.

## Разработка

```text
src/                 Дополнение, проверка, очистка, обновление и откат
vendor/              Изменённый сохранённый установщик оригинального Manager
tests/               Проверка готового пакета
bootstrap.sh.in      Шаблон автономного установщика
build.py             Сборка установщика на ПК
SOURCES.json         Происхождение исходников и контрольные суммы
```

Сборка на ПК с Python 3.9+:

```sh
python build.py
python tests/verify_package.py
```

После изменения исходников пересоберите `install.sh`: он содержит встроенный архив.
Оформление и анимации обрабатывает браузер. Удаление CSS-анимаций не обещает
значительного уменьшения RAM sing-box на роутере.

## Дополнительно: закрыть отдельную панель Forkozz

Если вы используете только LuCI, можно отдельно запретить доступ устройств
к API/Zashboard на TCP 9090, сохранив локальные запросы самого роутера:

```sh
sh extras/api-local.sh install
```

Команда выполняется на роутере из копии этого проекта; основной установщик
это ограничение автоматически не включает. Нужна уже установленная редакция 4.
Сохраняется правило fw4, работа sing-box/nfqws не перезапускается. Перед записью
проверяются firewall и ответ внутреннего API; при ошибке применяется откат.
После применения запрос к 9090 с ПК должен отвергаться; тот же запрос через
SSH с самого роутера может по-прежнему возвращать 200 — это ожидаемо.
Проверьте управление серверами в LuCI после установки.

Отмена:

```sh
sh /etc/zm-api-local/control.sh remove
```

Правило применяется только к input TCP 9090 для интерфейсов кроме lo;
транзитный трафик и другие порты не затрагиваются. Проверка на ПК выполнена
в модели shell/nft; реальная проверка nft проводится на устройстве до применения.

В локальной модификации также удалён блок Zashboard из настроек Forkozz,
включая ссылку, переключатель отдельной панели и её WAN-настройки. Внутренний
API и управление Forkozz через LuCI сохраняются. Ограничение входа на 9090
по-прежнему включается отдельно, как описано выше.
