# Аудит: состояние на 17 ноября 2026

## Что подтверждено

Пользователь подтвердил установку и работу редакции 3 на Cudy WR3000S v1
(ubootmod), OpenWrt 25.12.4 aarch64_cortex-a53. На устройстве выполнено обновление
Manager 5.083 → 5.085 и повторное применение очистки. Это закрывает прежнее
утверждение «редакция 3 не проверена на физическом роутере».
Новые изменения редакции 4 пока подтверждены локальными тестами.

## Ранее исправленные дефекты

- Подготовка UCI изолирована по конфигурационному каталогу и delta-хранилищу.
- Проверка всех файлов происходит до применения; есть отказ на неизвестном шаблоне.
- Откат возвращает компоненты, удалённые страницы и конфигурацию веб-сервера.
- Проверки владельца и прав каталогов работают без необязательной команды stat.
- Служебный маркер обновления исключён из замены видимых надписей.
- Одно задание cron, ранний пропуск неизменных файлов, закрытые временные каталоги.

## Метод проверки

Локальные тесты используют реальные sh/tar/JavaScript-parser; UCI, ucode, uid,
права Unix и reload в интеграционных сценариях моделируются. Проверяются
установка/повторная установка, отсутствие лишних записей, сохранение cron/Forkozz,
неизвестные шаблоны, ошибочная запись/reload, принудительное завершение и recovery.
Новые сценарии: альтернативное имя/порт слушателя, повреждённый архив, сохранение
первого снимка, прямой загрузчик с отказом на HTML/обрезанный файл/ошибку сети.

Источник семантики UCI: [официальный исходник](https://github.com/openwrt/uci/blob/master/cli.c).
Версии/источники пакета записаны в SOURCES.json, результаты — в TEST-RESULTS.json.
Отчёт не является сертификатом безопасности и не объявляет весь Manager защищённым.
