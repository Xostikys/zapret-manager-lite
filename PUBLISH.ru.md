# Публикация

1. Войдите на GitHub как Xostikys. Нажмите «+» → New repository.
2. Название `zapret-manager-lite`, видимость Public, создайте репозиторий.
3. Распакуйте `zapret-manager-lite-github.zip` на ПК.
4. В репозитории выберите Add file → Upload files. Загрузите СОДЕРЖИМОЕ
   распакованной папки, включая папки src и vendor. Сам ZIP загружать не нужно.
5. Проверьте: `install.sh` должен лежать в корне репозитория, ветка — main.
6. Нажмите Commit changes. Теперь команда из README готова к использованию.

Публикуется только подготовленный пакет. Папку outputs целиком не загружайте:
в ней есть диагностические отчёты и сохранённые конфигурации вашего роутера.
