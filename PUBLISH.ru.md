# Публикация редакции 3

1. Распакуйте zapret-manager-lite-luci-only-v3.zip.
2. Загрузите его содержимое в Xostikys/zapret-manager-lite с заменой файлов.
   Сохраните папки src, vendor и tests. Сам ZIP в корень вместо исходников не подходит.
3. README содержит команду установки. Она получает ту версию install.sh,
   которая реально опубликована в main; локальный архив сам не обновляет GitHub.
4. Сначала проверьте этот выпуск на своём роутере. В описании выпуска укажите,
   что это локальная модификация StressOzz, и сохраните LICENSE/NOTICE.
5. Для повторяемой установки можно использовать URL с commit вместо main.

Перед загрузкой после своих изменений: python build.py; python tests/verify_package.py.
Не публикуйте экспорты роутера, пароли, подписки Forkozz и пользовательские конфиги.
