Локальная очистка и облегчённое оформление Zapret Manager
=======================================================

Установка из Windows:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Local-UI.ps1 -Router 192.168.1.1

Устанавливается поверх исходного Manager. Предыдущие очистки можно оставить;
повторно запускать их установщики не нужно. После установки нажмите Ctrl+F5.

Что меняется
------------

- Удаляются рекламные ссылки VPN/Telegram в шапке дашборда.
- Удаляется пункт «Спасибо и поддержка». Его JS-страница содержит только
  список авторов из ТЕКУЩЕЙ версии. Лицензии и исходники не удаляются.
- Убираются отдельные Web-кнопки в «Системе» и известные standalone Web-активы.
  Если отдельный Web-сервер включён, установка останавливается до правок:
  сначала выключите его в исходном Manager. LuCI не выключается.
- Карточки и основные панели становятся прозрачными, наследуют текст темы.
  Диалоги/уведомления сохраняют читаемую поверхность. Зелёные индикаторы,
  выбранные кнопки, прогресс и переключатели остаются различимыми.
- Отключаются CSS-анимации, переходы, пульсации, тени и backdrop blur только
  у элементов Manager. Размытие секретов и системная тема LuCI сохраняются.

Автоматическое восстановление после обновления Manager
------------------------------------------------------

Скрипты находятся в /etc/zm-local-ui. Штатный cron раз в пять минут запускает
короткую проверку контрольных сумм. Постоянного нового процесса нет. При
неизменных файлах выполняется только чтение, без перезаписи UI/flash.

Изменившиеся файлы должны дважды подряд дать одинаковые суммы, поэтому
повторная очистка обычно происходит через 5–10 минут после завершения
обновления. Открытую страницу затем нужно обновить с Ctrl+F5.

Сохраняются текущие записи меню, включая Forkozz. common.js, build.txt,
backend/RPC и сам установщик Manager не переписываются. При незнакомой
структуре JS/CSS очистка пропускается целиком и записывает сообщение
в системный журнал. Произвольные будущие версии не гарантируются.
Если новая версия изменит шаблоны, понадобится обновить этот пакет.

Немедленное применение и диагностика:

    ssh root@192.168.1.1 "sh /etc/zm-local-ui/tick.sh apply"
    ssh root@192.168.1.1 "logread -e zm-local-ui"

Требуются работающий системный cron и штатный ucode с fs. Если страница или
папка Manager находится по символьной ссылке в /tmp, автоматическая очистка
её не меняет: выключите в исходном Manager режим «Панель в оперативной памяти»
и повторите установку. Сам пакет этот режим не переключает.

Оперативная память
-----------------

Упрощение оформления разгружает прежде всего браузер, а не nfqws на роутере.
Пакет выводит разовый снимок MemAvailable, Shmem и режима хранения панели.
Это не измерение сэкономленной памяти. Для поиска основных потребителей
нужны отдельные данные роутера; значения экономии здесь не выдумываются.

Режим «Панель в оперативной памяти» экономит FLASH за счёт RAM. Если цель —
снизить расход RAM, оставляйте обычное хранение панели на flash. Фоновые
проверки Manager могут выполнять сетевые проверки и восстановление сервисов;
пакет сохраняет их текущую настройку, чтобы не нарушить Forkozz и игры.
Параметры sing-box, nfqws, firewall, DNS, VPN и offloading не меняются.
Системный cron не перезапускается, другие его задания сохраняются.

Отмена
------

    ssh root@192.168.1.1 "sh /etc/zm-local-ui/restore.sh"

Сначала удаляется только наше cron-задание и отключается повторная очистка.
Затем восстанавливается резервная копия UI непосредственно перед последним
применением. Хранится одна такая копия, без накопления архивов после каждого
обновления. Если UI с тех пор снова обновился или был изменён вручную, старые
файлы поверх новых не восстанавливаются; защита при этом уже отключена.
Резервные копии прошлых пакетов очистки остаются отдельно.

Защита рассчитана на обновления Manager. Перепрошивка, удаление /etc/zm-local-ui
или очистка пользовательского crontab могут её убрать: тогда установите заново.

Проверки и ограничения
---------------------

Локальные проверки описаны в local-ui-verification.json рядом с архивом. Настоящий
ucode запускается на роутере ДО записи UI. На этом ПК используется модель
его функций; она не заменяет испытание под OpenWrt. Фактический вид в теме
роутера и расход RAM оцениваются после установки. Встроенной сетевой проверки
игр нет — этот пакет не меняет игровую обработку.
